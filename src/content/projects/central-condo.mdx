<HighlightCard title="Multi-tenant architecture from a single codebase">
A `condoContext` middleware resolves the tenant via an `X-Condo-Slug` header and scopes every query — residents, packages, announcements, store — by `condo_id`. The same API and the same mobile app serve multiple condominiums with no per-tenant deploy.
</HighlightCard>

<HighlightCard title="Digital signature capture, privacy by design">
Residents and staff sign for package pickups with a canvas-based signature pad. A scheduled server-side job auto-purges the base64 signature images past a configurable retention window while preserving the audit record — a genuine data-retention feature, not an afterthought.
</HighlightCard>

<HighlightCard title="Real CI, not just linting">
GitHub Actions spins up an actual Postgres 15 service container, runs the Knex migrations, and executes the full integration test suite on every change to the server — the same schema and data flow the app depends on in production.
</HighlightCard>

<HighlightCard title="iOS Keychain / AutoFill credential sharing">
`associatedDomains` (`webcredentials:centralcondominio.com.br`) lets iOS Keychain autofill save and offer the same login across the web admin panel and the mobile app, gated behind Face ID / Touch ID via the OS autofill layer.
</HighlightCard>

<HighlightCard title="Full app-store-readiness engineering">
Account deletion flow, public privacy/support/account-deletion pages, `.well-known` routes, and seeded demo-condo data for App Store reviewers — the full mobile release lifecycle, not just feature code.
</HighlightCard>

<HighlightCard title="End-to-end push notification pipeline">
Expo push tokens are registered per device/platform, fanned out server-side via Expo's push API with Android notification channels, and wired into role-based "send announcement" flows in both the web and mobile admin surfaces.
</HighlightCard>

<HighlightCard title="Pragmatic, idempotent operations">
Supabase-hosted Postgres for staging and prod, guard-clause migrations safe to re-run across environments that may be partially migrated, a Dockerized API deploy, and EAS OTA updates for shipping JS fixes without an App Store review cycle.
</HighlightCard>

<CodeSnippet
  filename="condoContext.ts"
  lang="typescript"
  code={`export async function condoContext(request: FastifyRequest, reply: FastifyReply) {
  const slug = request.headers['x-condo-slug'];
  const condo = await knex('condos').where({ slug }).first();
  if (!condo) return reply.status(404).send({ error: 'Unknown condo' });

  // every downstream query is scoped by condo_id — same API, many buildings
  request.condoId = condo.id;
}`}
